# 1.0.2 验收记录

日期：2026-10-18。版本：1.0.2（构建 8），从 1.0.1 升级。

## 本轮变更

- 每群独立保存手动续读点、自动进度和跳转前返回位置，三个按钮各自显示消息日期时间。「从这里继续」只更新手动点。
- 阅读区新增「进入待机」：不选中任何群，所有勾选同步的群继续收取新消息、累计各自未读。待机状态跨重开保存，点击某群只清除该群角标。
- 待机另存实际停留画面，支持先去别群再回来；这个内部位置不会改写三个用户阅读位置。
- 联网搜索和深度思考横向并排、点击切换明暗，按钮与实际请求能力一致；固定推理或未知能力明确显示限制。
- 「开始 AI 总结」自动收起窗口，在右侧展示原群、时段、加载/批次/合并进度及停止入口。切群、待机、关闭弹窗不取消任务。
- 资料默认折叠，压缩偏好、快捷问题和输入控件，为回复让出高度。

## 验收边界

合成界面测试使用合成资料。真实账号阅读验收访问了本机资料；授权后的真实 AI 成功证据来自观察用户自行发起的图片翻译，本轮没有代用户再提交群聊或附件。真实账号数据备份、日志及截图不在源码包内。自动化通过不代表微博所有原生聊天功能已经逐项实测；本轮保留官方聊天入口。

后台模型任务需要应用保持打开，退出会停止请求并保存已完成内容。待机同步需要应用打开且 Mac 未休眠；休眠或断网会延迟，恢复后继续补收。联网信息和 AI 总结仍受服务能力、检索覆盖及模型输出影响。

本发行使用 ad hoc 签名，未做 Apple Developer ID 签名或公证；双架构编译不等于 Intel 真机验收。安装包和源码包不包含用户聊天、附件、偏好、登录态或 Key。
