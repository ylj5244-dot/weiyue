# 微阅 1.0.9 验收记录

验证日期：2026-10-19。基线：已交付的 1.0.8（构建 14）；本轮目标：1.0.9（构建 15）。全部测试使用合成账号、临时目录和模拟 AI；不调用用户真实服务或读取真实密钥。

## 已完成的功能检查

- 历史标题：实际 WKWebView 验证旧记录自动补题、新讨论自动拟题、追问后更新、两行历史首页展示、主提问优先、暂停/恢复、格式错误重试、删除及迟到结果隔离。
- 保存：使用真实 StateStore 写入临时目录，再重新加载页面，标题和元数据保留；已经拟题且内容未变化的讨论不重复请求。无效标题元数据不能覆盖已保存档案。
- 阅读间距：实际测得独立五档连续正文间距为 24 / 25 / 26 / 34 / 46 px。默认 26 px；数字包含操作栏与正文留白，并非正文行高。
- 皮肤：三套内置选择可用；青绿与上一版样例配色一致；青绿、Claude Code 日夜共四套自定义配色分别验证。
- 逐条背景：两套新皮肤在同一 ID 的连续消息内轮换三种底色，日夜共 12 色。实际界面测得正文与底色对比均不低于 7:1，夜间时间信息不低于 4.5:1；筛选重排、长列表虚拟滚动、选中、定位和关注提示均通过。已目检四张完整阅读截图。
- 外观持久化：旧版设置迁移、跟随/独立间距、同名导入按 ID 区分、切换皮肤保留字体、重载恢复及恢复默认均通过。
- 阅读布局：1120×700 窗口设置区滚动及底部按钮可达；浮动操作保留空间；长列表深处切换间距保持消息位置。

- 原生档案：19/19 通过，含新标题持久化与损坏元数据拒绝。
