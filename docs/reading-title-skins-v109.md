# 微阅 1.0.9 使用说明

版本：1.0.9（构建 15）。适用 macOS 14 或更新版本，安装包同时包含 Apple Silicon 与 Intel 架构。

## 历史讨论自动拟题

点击右侧「历史」，首页直接显示每条讨论的主题标题。旧记录会使用当前设置的 AI 模型逐条补齐；新的讨论在收到回复后自动拟题，继续追问后也会按更新后的讨论内容重新概括。

拟题时会保留原来的标题，成功后再替换。它根据已保存的提问、回答与少量来源文字概括具体主题，标题最多 32 个字符。历史列表可显示两行，悬停可以查看完整标题。原提问、回答、资料快照及讨论顺序仍然保留。

- 「暂停拟题」暂停当前队列；「继续拟题」恢复。
- 没有成功生成的记录保留原题，可点击「重试」。已经生成且内容未变化的标题不会重复请求。
- 遇到长时间无响应会取消该条请求后再继续；若未能确认取消，队列暂停，点击「继续拟题」后重新确认。
- 开始 AI 提问、翻译或读取资料时，标题任务先让出，正文操作结束后继续。
- 删除的讨论不参与拟题；切换账号时取消旧账号任务，迟到结果不会写入新账号。
- 尚未配置 AI 时，历史仍然可用。点击「设置 AI」完成配置，再打开历史即可补齐。

拟题与正文讨论使用同一套模型和 API 配置，每条标题是一次独立的模型请求。历史较多时会逐条处理；关闭历史面板后仍可继续，重新打开可查看进度。不会为拟题开启联网搜索或直接读取附件文件。

## 行距与同一成员的消息间距

入口：右上角齿轮「设置」→「阅读与皮肤」。

「正文阅读密度」保留紧凑、偏紧、标准、舒展、宽松五档，调整正文行距和成员分组间距；字号仍由阅读区原来的字号下拉框控制。

「同一成员消息间距」调整同一个发言块内，每一条消息之间的距离：

| 选择 | 行为 |
|---|---|
| 跟随阅读密度 | 默认设置，沿用上一版密度对应的间距；调整正文密度时一起变化。 |
| 独立五档 | 单独选择紧凑、偏紧、标准、舒展或宽松。之后调整正文密度，不会覆盖这一选择。 |

默认标准档保持原来的阅读距离。舒展、宽松档会明显拉开连续消息。各档保留上方浮动操作按钮需要的空间，复制、书签、收藏等按钮不会压住正文。切换密度、间距或字体时尽量保留当前消息和阅读位置；接近列表末尾时按可滚动范围停靠。

## 三套内置皮肤

同一设置页的「界面皮肤」中直接选择：

| 皮肤 | 配色 |
|---|---|
| 微阅原生 | 原来的银白日间、石墨夜间。 |
| 纸页 · 青绿 | 上一版样例的纸色、青绿配色，现已内置。 |
| Claude Code 风格 | 暖白、陶橙与炭灰配色，为微阅制作的风格皮肤。 |

三套皮肤均可配合顶部「外观」选择日间、夜间或跟随系统。切换皮肤保留当前字体。导入的皮肤单独列在「已导入皮肤」，同名项目也不会覆盖内置项目。

青绿和 Claude Code 两套新皮肤在专注模式按消息逐条轮换三种协调的背景色。同一个 ID 的连续消息也交替显示；成员归组、姓名、书签、关注提示和阅读位置标识继续保留。日间、夜间分别使用适配的配色，筛选或滚动长列表时按当前消息顺序排列。微阅原生继续使用原来的成员分组配色。

## 原来的导入功能与保存

仍支持导入微阅 JSON 皮肤、本机字体及 TTF／OTF 字体文件。皮肤最多 64 KB，单个字体最多 32 MB。导入皮肤中的 `fontFamily` 字段仍可读取、校验，但从 1.0.9 起不自动覆盖当前字体；需要更换字体时使用独立的字体下拉框。

外观设置修改后立即保存，下次启动继续生效。点击「恢复默认」恢复标准正文密度、跟随密度的消息间距、微阅原生皮肤与系统默认字体；已经导入的文件继续保留。

## 关闭窗口与安装更新

点击左上角红色关闭按钮，只关闭窗口，微阅在后台继续运行。点击 Dock 图标恢复原窗口；菜单「退出微阅」或 Command+Q 才真正退出。

更新时先按 Command+Q 退出旧版，再打开新版 DMG，把微阅拖到原来的应用位置替换。同一台 Mac 的阅读资料、讨论、字体、外观设置及钥匙串中保存的 Key 继续使用原目录。

安装与换机详情见 [安装、迁移与构建说明](install-and-build.md)。
