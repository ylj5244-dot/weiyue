# 微阅 1.0.6（构建 12）验收记录

验收日期：2026-10-19。本版根据阅读界面的反馈调整同步栏、消息操作、三栏拖动和选择框，并把手动续读点、书签、单条收藏改为开关。测试使用临时账号目录、合成群聊和模拟模型响应，没有读取真实账号资料或调用真实微博、付费模型服务。

## 修复与行为

- **同步栏上移。** 同步状态、「立即同步」与「加载更早 500 条」移入阅读位置按钮右侧，不再占用独立的底部状态行。窄栏有序换行，并收起同步时间等次要信息。阅读位置的完整时间保留在对应按钮的提示中。
- **浮动消息操作。** 鼠标悬停或键盘焦点进入对应消息时，右上方出现操作条，保留续读点、书签、收藏、翻译和讨论的顺序。只有含英文的消息显示翻译入口。按钮预留必要空间，显示和隐藏不改变卡片高度；正文和按钮不互相覆盖。长名称省略显示，完整姓名和成员 ID 可通过提示查看。
- **拖动停止边界。** 原先布局计算仍允许中间阅读区缩到 430px，与实际控件所需空间不一致。现在 CSS、鼠标拖动、键盘调整、双击复位和侧栏展开使用同一组约束：左侧至少 220px、阅读区至少 560px、右侧至少 320px。达到可用空间边界后停止继续收窄。窗口不足以容纳三栏时自动收起侧栏，放大后恢复；不会覆盖保存的手动收起状态。拖动以另一侧当前可见宽度计算，避免旧的宽度偏好导致另一栏跳动。
- **三个状态开关。** 手动续读点、书签和单条收藏均支持点击开启、再次点击取消，文案和选中状态同步更新。取消手动续读点不改动自动进度或临时返回位置；点击另一条则移动手动点。书签与单条收藏取消后进入对应的「最近删除」，重新点击优先恢复同一记录并保留备注、快照和名称。单条收藏直接保存，不弹命名窗口；多条消息组成的合集和已有讨论不受此开关影响。
- **保存与并发。** 保存中拦截重复点击；失败恢复原按钮状态并允许重试，复用同一个记录 ID。回滚只处理本次修改，不覆盖同期产生的阅读进度、备注、名称或讨论引用。账号切换后隔离旧账号回包。
- **选择框对齐。** 选择框从姓名行移到各条消息正文起始处；同一人连续发言的首条、后续条，以及带书签、续读点和译文的消息使用同一对齐规则。保留逐条选择与来源快照禁用行为。
