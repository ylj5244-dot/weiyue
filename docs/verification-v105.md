# 微阅 1.0.5（构建 11）验收记录

验收日期：2026-10-19。此版本修复 1.0.4 的设置按钮错误禁用与消息菜单裁切，并按新的操作顺序调整阅读界面。测试使用合成群聊、临时账号目录和模拟模型响应；未读取真实账号资料或调用真实微博、付费模型服务。

## 问题与修复

- **设置入口发灰。** 原先本地偏好和关注设置共用了模型查询、AI 任务的锁；保存设置结束后，控件还可能停留在保存中的禁用状态。现在本地设置独立判断可用状态，并在保存结束时刷新按钮。模型查询或 AI 工作不会阻止打开本地偏好与关注管理。模型接口、Key 等设置在任务进行时仍保留相应保护。一次 AI 请求使用开始时的偏好快照，途中修改偏好影响后续请求。
- **消息菜单被裁切、主次不清。** 删除消息中的悬浮更多菜单，操作行放入消息正文之后，支持自动换行。依次显示「从这里阅读 → 加入书签 → 加入收藏」，含英文的消息再显示「翻译成中文」；「加入讨论」保留为后置操作。重点关注管理仅放在「设置 → 重点关注人员」。
- **书签要先填备注。** 点击「加入书签」直接保存，不打开备注窗口或离开阅读；连续点击保存中的按钮不会重复创建。保存失败可以重试，并复用同一个书签。备注入口移到左侧本群书签的「备注」和书签页的「添加备注 / 编辑备注」。修改备注不改变原文快照、原创建时间或其他书签；失败保留输入草稿。
- **翻译入口条件。** 正文含英文单词或常见英文缩写才显示单条翻译入口；纯中文、数字、标点，以及只有链接、邮箱或代码的文本不显示。中英混排显示。该判断是轻量文本规则，不是完整语言识别。译文仍使用当前模型，显示在原消息下方。
- **本次要求。** 删除右侧 AI 的「本次要求」入口、标签和弹窗。新需求直接输入对话框。历史记录中已有的字段保留，但不会被自动附加到新请求；长期个人偏好继续生效。
- **标记配色。** 重点关注的姓名、标记和边线使用红色；手动续读点保留金色。二者可在同一条消息上同时显示，保留原三色发言分组与原有书签标记。
- **查看最新。** 消息操作行增加高度后，原来直接滚到估算底部可能停在最后一条上方。改为通过虚拟列表定位最后一条消息，按实际高度对齐；跳转前位置仍保存。

## 构建与边界

本版面向 macOS 14 及以上，提供 arm64 与 x86_64 通用应用。本机使用 Apple Silicon 完成界面验收；Intel 仅完成交叉编译与架构检查，未在 Intel 真机运行验收。使用 ad hoc 本机签名，未进行 Developer ID 签名或 Apple 公证。

源码采用文件白名单导出，含运行资源、构建/打包脚本、测试及文档。安装包和源码不含真实聊天记录、附件缓存、登录态、个人偏好或 API Key。真实微博页面及模型服务的可用性仍取决于外部服务，本次未重新进行真实账号联网验收。
