# 微阅 1.0.4（构建 10）验收记录

验收日期：2026-10-19。此版本在原 1.0.3 功能基础上调整菜单与阅读操作，并增加重点关注和单条行内翻译。测试均使用虚构群聊、临时账号目录或模拟模型响应，不读取真实聊天记录，不调用付费模型接口。

## 本次完成

- 导航统一为「群聊 / 书签 / 资料库」。侧栏展示本群书签，书签页支持所有群聊与单群筛选，删除和恢复保留。
- 同步选择移入「我的群聊 → 管理」。保存选择不会切换群聊或离开待机；取消不保存；保存失败保留此前同步选择和未读提醒。
- 顶部仅保留「回到手动续读点 / 返回跳转前」，无对应位置时隐藏。后台自动保存与恢复阅读位置保留；旧锚点恰好位于被隐藏通知时恢复到相邻可见消息。
- 长期个人偏好移到「设置 → 个人偏好」；当前讨论要求移到讨论标题旁的更多菜单，设置后显示小标签。已有对话隐藏快捷提问条，快捷提问仍可在个人偏好库调用。
- 姓名或 ID 去除首尾空白后恰为「粉丝群」的系统通知在专注阅读中隐藏。原始数据、历史、书签和收藏不删除；近似名称及正文提及「粉丝群」的普通消息保留。
- 「设置 → 重点关注人员」可搜索已见成员或手动添加完整 ID。按账号隔离、按 ID 跨群生效，同名不同 ID 不混淆。姓名、星标、左侧标线突出，保留原三色分组；最多 200 人。
- 消息「加入收藏」持久保存完整快照，保存后继续当前阅读，不改变右侧讨论。原「加入讨论」位于消息更多菜单；批量收藏和批量加入讨论保留。
- 单条文字翻译使用当前所选模型，只提交该条原文，译文显示在原消息下方。支持流式进度、收起、重译、取消和取消失败后再次取消。完整译文绑定账号、群、消息 ID 和原文，保存最近最多 100 条并限制总大小；未完成内容明确标注，不作为完整结果持久缓存。批量翻译、图片翻译、文档解读仍使用右侧工作区。

## 构建及验收边界

应用面向 macOS 14 及以上，包含 arm64 和 x86_64 双架构，使用本机 ad hoc 签名，未进行 Developer ID 签名或 Apple 公证。Apple Silicon 上完成原生界面验收；Intel 仅交叉编译与架构检查，未在 Intel 真机验收。实际微博页面与真实模型服务的可用性依赖外部服务，此次未用用户账号重新调用。

安装时先退出旧版，再替换原位置的应用；本次发行包与源码不包含聊天、附件、登录态、账号密钥或测试账号数据。
