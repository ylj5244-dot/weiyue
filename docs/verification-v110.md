# 微阅 1.0.10 验收记录

验证日期：2026-10-21。基线为 1.0.9（构建 15），本版为 1.0.10（构建 16）。测试使用合成账号、临时目录及模拟服务；未对用户真实聊天执行清理，也未调用真实 AI 服务。

## 功能与数据保护

- 二级存储页：核验分类占用、磁盘分配大小、账号数量说明、路径展示与手动清理入口。临时文件测试包含 macOS 路径别名和符号链接。
- 自动清理：默认关闭，严格接受 1–4 整天；按发送时间保留边界、未知时间及受保护消息。书签及最近删除、收藏、讨论、阅读锚点、未发送资料、预览与勾选项、导入文件受保护。
- 原生清理事务：先保存新的记录与待删除引用，校验并缩减备份，再删无引用缓存；跨账号、共享文件、符号链接及过期版本被拒绝。缺少缓存清单的残留目录、权限失败后的重试、保存后统计失败及毫秒边界均有回归覆盖。
- 清理异步整合：实际页面通信函数验证清理等待原生最终确认，避免超时后状态失步；编辑弹窗打开时延后自动清理，清理完成恢复操作按钮。预览按附件下载预算等待并隔离迟到结果。
- 分类搜索：全部、链接、图片、文件、视频；正文、附件名与 URL 检索；与成员、群聊及日期条件组合。
- 关注发言：按稳定成员 ID 跨群聚合，同名不同 ID 不混淆；来源群跳转、组合筛选、关注提示，以及不写入群阅读进度的临时锚点恢复。
- 自己的发言：按当前账号及发送者 ID 判断，专注阅读中卡片靠右，保留可见姓名、时间与「我」标记。
- 连续消息间距：五档额外间隔 0、8、20、38、64 px；在默认字号与密度下实际正文间隔 24、32、44、62、88 px。最高档重载后仍为 88 px，原来的跟随密度模式保留。
- 附件布局：1488 与 1120 像素宽窗口、日夜模式下核验横图、竖图、多图原比例及居中；文件标题与操作区不重叠、不横向溢出。预览关闭后原讨论及资料保留。

## 测试结果

- JavaScript：336/336 通过，包含新增清理等待、弹窗并发、解锁、跨群锚点和官方来源群跳转回归。
- 原生全套通过：25 组档案存储、跨账号并发与备份压缩、媒体、可撤销清理、存储统计、保留策略、自动清理、字体皮肤、文档/OCR、AI 流式收发、联网搜索和 92 项标题检查。
- 完整窗口验收 270 项通过，使用 6006 条合成消息；书签与手动续读点点击后约 4 ms 显示目标状态，并核验保存失败回退和重试。主流程 266 项，实际页面重载 4 项。
- 跨群关注视图在调整字号、调整消息间距和模拟消息同步后，测试消息的视口偏移始终为 -24 px；自己的姓名、时间与「我」标记均保持可见。
- 原有外观与阅读位置回归通过：三套皮肤、日夜配色、字号保留、虚拟列表位置、五档间距、重新加载和重置。
- 原生后台生命周期回归通过：关闭窗口后进程和网页会话保持，Dock 重开保留会话；明确退出会暂停同步、保存并等候文件操作结束。
- 附件操作回归通过：两种窗口宽度下工具条和标题无重叠，图片/文档分别解读与翻译、加入讨论、原生另存菜单、访达定位、官方来源与新版预览路由均正常；切换账号后的迟到结果被忽略。
- 实际原生预览 47 项断言通过：仅绑定 127.0.0.1 的 HTTP 夹具，实际页面加载、点击链接、前进、后退、刷新、标题和地址回传；独立临时会话且无应用消息桥。
- 实际临时 PDF 与 DOCX 在 QLPreviewView 渲染，四张网页/文档截图均已目检，文档正文另经 OCR 核对。PDF 的远程绘图层改用合成窗口截图取得，未把空白缓存图算作通过。

## 保存性能

同机、优化编译、三次采样中位数，均使用合成数据：

| 消息量 | 优化前保存 | 优化后保存 | 降幅 |
| --- | ---: | ---: | ---: |
| 6000 条 | 2103 ms | 441 ms | 79.0% |
| 10000 条 | 4798 ms | 985 ms | 79.5% |

这组数字测量原生完整保存，不是点击反馈延时。界面另核验目标状态立即显示，后台保存失败可回退。设备、资料大小和附件数量不同，耗时会变化。

## 构建与验证范围

通用构建包含 arm64 与 x86_64，最低 macOS 14，使用本机 ad hoc 签名。实际运行与窗口验证在本机 Apple Silicon 上完成；Intel 仅交叉编译。网页和文档预览验证使用本地合成内容，不据此声称任意外部站点、登录流程、全部文档格式或远端 AI 服务都已验收。

复验入口：`scripts/test.sh`、`scripts/test-storage-preview-ui.sh`、`scripts/test-reading-appearance-v109-ui.sh`、`scripts/test-background-lifecycle-ui.sh`、`scripts/test-attachment-actions-ui.sh`。图形测试需在已登录的 macOS 桌面运行。
