## ✨ 本次重点

📐 顶部更紧凑：宽阅读栏将群信息和常用工具分成两行。1024 像素阅读栏实测占用高度从 244 降到 98 像素，正文获得更多空间；窄窗口自动换行。

🔄 同步详情按需展开：群名旁保留状态和“历史未完整”提示，点击查看进度、本地记录范围、立即同步及加载更早 500 条。修复官方模式收新消息后菜单数量滞后的问题。

🔍 筛选集中在一处：成员与日期收进筛选菜单；全部发言、只看关注、搜索和消息类型仍可直接切换。生效条件、匹配数量及清除入口按需显示。

📍 阅读位置放到右下角：返回跳转前、最新和手动续读各自保留。查看最新不覆盖手动点，返回可恢复原消息和滚动位置，多选时避开底部操作栏。

## 🧩 从 1.0.9 升级还会获得

👀 当前群关注阅读，关注成员与连续发言更清楚；短消息背景收窄，长消息自然换行，自己的消息靠右。五档连续消息间距可单独调整，内置 75 个常用微博表情。

⚙️ 设置按阅读与皮肤、关注人员、个人偏好、AI、存储分类。支持查看分类占用、手动清理和可选的自动清理；自动清理默认关闭，已保存的书签、收藏和讨论引用受到保护。

## 📦 安装与验证

先正常退出旧版，再把 DMG 中的“微阅”拖入应用程序替换；保留原有资料目录即可继续使用本机记录与设置。

应用使用本机 ad hoc 签名，尚未完成 Apple Developer ID 签名和公证。首次打开如被系统阻止，按随包安装说明操作。Intel 已交叉编译并核对架构，实际图形验收在 Apple Silicon Mac 上完成。

本版完成 357 项 JavaScript 回归、462 项紧凑阅读原生检查及 400 项原有阅读界面回归。界面检查使用合成账号和消息，不代表外部微博或模型服务始终可用。

源码包包含项目代码、资源、构建脚本、测试、文档及 MIT 许可证，不包含聊天记录、登录态或 API Key。第三方表情素材说明随源码提供。
