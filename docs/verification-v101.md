## 真实联网调用

在已安装新版中打开联网开关，并提交「请联网核实 DeepSeek 官方 Search API 的请求路径，只用两句话回答并附来源。」时，macOS 阻止新版读取已保存的 Key。应用正确提示进入设置点击「授权已保存的 Key」并完成系统钥匙串确认；没有更换 Key 或模型，也没有绕过系统授权。

用户随后完成系统授权。2026-10-18 11:44 再次提交同一公开问题，真实 Search API 返回 5 个来源，其中 3 个为 DeepSeek 官方文档；模型在界面完成回答，并将 `POST https://api.deepseek.com/v1/tools/search` 链接到实际来源。界面显示「已完成 · 4 秒 · 9667 tokens」，来源列表展示检索时间、搜索词、摘要及发布时间；官方文档缺少发布时间时明确显示「未提供发布时间」。这是本机真实账号的搜索与模型联合调用，未选中私人聊天或附件。

存档中的 webSearch.status 为 success，5 个来源及其链接已持久保存。随后关闭联网开关、正常退出并重开，实际回答与来源仍在，开关保持关闭。这次真实调用验证服务可用，不表示之后所有问题都能得到最新、完整或准确的信息，仍受搜索覆盖和服务状态影响。

## 接口依据及限制

依据 [DeepSeek Search API](https://api-docs.deepseek.com/zh-cn/api/search/) 与 [官方使用指南](https://api-docs.deepseek.com/zh-cn/guides/search/)，于本轮核对。只调用固定官方搜索地址，未给其他兼容服务配置搜索功能。单次最多五个来源，正文有长度上限，可能退回服务返回的摘要；不能保证互联网信息永远最新或准确。搜索单独计费，服务方权限、余额、限流和站点覆盖仍影响结果。

安装包采用 ad hoc 签名，未做 Apple Developer ID 签名或公证。双架构编译、签名和 Mach-O 检查不等同于在独立 Intel Mac 上运行验收。应用包及源码包不携带用户聊天、收藏、偏好、附件、登录态或 Key；新 Mac 需单独迁移资料、登录并配置 Key。
