# 微阅 1.0.4 产品逻辑调整

依据用户批准的四项优先方案和补充要求实现，保留原有资料、同步、书签、收藏、讨论及阅读位置数据。

- 导航统一为群聊、书签、资料库。添加书签用于留位置；加入收藏真正保存消息快照；加入讨论作为独立操作保留。
- 群列表点击只切换阅读。同步勾选移入“管理同步群”对话框，提交时保存，不改变当前阅读群或切换到微博网页。
- 侧栏显示本群最近书签；完整书签页提供当前群/全部群筛选。最近删除作为二级操作保留。
- 顶部删除回到自动进度按钮，保留回到手动续读点、返回跳转前，未设置时隐藏。后台自动位置恢复继续工作。
- 长期个人偏好入口移入设置；本次要求移入讨论更多菜单，生效时显示轻量标签。右侧空资料和空偏好状态收敛。
- 专注阅读过滤姓名或 ID 精确为“粉丝群”的消息，保留底层记录。普通消息正文包含此词不受影响。
- 当前账号可自由选择或输入重点关注成员 ID，同 ID 跨群生效，姓名/星标突出，三色发言块与书签标识仍可识别。
- 单条文字翻译使用当前所选 AI 模型，只提交该条原文；译文在原消息下方展示，支持进度、取消、重试、收起和成功结果保存。右侧讨论不被重建或替换，AI 请求互斥、账号切换和退出保持正确。
- 发行版本 1.0.4（构建 10），交付双架构应用、DMG/ZIP 和完整源码。

实施分工：根任务负责菜单/布局/应用集成，独立模块分别实现关注人员和行内翻译；独立原生界面验收覆盖新功能与既有重要流程。

验收重点：数据不丢失、命名与行为一致、各状态入口可达、同步管理无导航副作用、隐藏通知后分组与位置正确、关注隔离、行内翻译的模型与内容边界、持久化及取消/失败、日夜/窄窗口显示。
