# 1.0.11 阅读布局修正

依据用户六张实际截图和补充确认：中间阅读区既要整组强化关注成员，也要提供只看关注切换。移除左侧独立关注入口。

1. 当前群的专注阅读提供「全部发言 / 只看关注」。默认全部，筛选保持群上下文，不污染正常阅读进度。关注的连续发言仍按账号、群、成员、日期归组，仅首条显示姓名与关注徽标；连续部分沿用整组边线和底色。
2. 独立消息间距扩大为五档 0、16、40、80、144 px 额外间隔，并明确即时应用；提供设置内的连续消息预览，避免只能靠数字判断。保持原有跟随密度选项，保存后重启有效。
3. 用户补充确认：长图适配只针对点开后的独立图片预览。按宽高比例自动识别长图，默认按窗口可用宽度放大，纵向滚动阅读；窗口变化时重算宽度并保留阅读位置。聊天列表缩略图维持紧凑居中；普通图片仍默认完整适配窗口，手动缩放和拖拽保留。
4. 微博方括号表情（包括示例 [二哈]）渲染为行内表情图，使用可信微博表情资源的本地随包映射，保留 alt、复制与检索原文；未识别标记保持原文，禁止把任意 HTML 当作消息渲染。
5. 缩短搜索框，并把类型按钮放在同一行。使用阅读区容器宽度适配；窄窗口合理换行或折叠辅助条件，不横向溢出，成员、时间、字号和时段总结继续可用。
6. 右侧网页按容器适配，优先呈现可阅读的正文宽度，窗口或右栏宽度变化后重排；不把整张桌面网页缩成不可读的字。保留地址、导航、外部打开及独立浏览器隔离。用固定宽度桌面文章夹具和响应式网页验收。
7. 设置改为左分类右内容：阅读与外观、重点关注、AI 服务、个人偏好、存储与清理。保持已保存的模型、Key 状态、偏好、字体、皮肤和清理设置；内容变化、保存、返回和关闭路径明确，不因切换栏目丢失未保存 AI 表单。

验收以用户截图中的问题为准：同一关注成员三条连续消息只能有一个可见姓名栏；长图点开后文字具有实际阅读尺寸、缩略图不变；默认与最大间距有明显差异；[二哈] 显示正确资源；不同阅读区和右栏宽度无横向裁切；设置分类可键盘操作且保存行为原样可靠。发布范围为本机安装与本地安装包，不主动发布到 GitHub。

补充要求：专注阅读隐藏完整撤回提示，保存记录和官方聊天不变。最后新增色块宽度自适应：以当前字体和消息实际内容测算，连续成员组采用该组最长内容的统一宽度，保留操作栏的必要空间，以阅读区宽度为上限；颜色、分组和控件行为不变。
