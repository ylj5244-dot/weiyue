# 微阅 1.0.3（构建 9）阅读显示验收

验收日期：2026-10-19。开发环境：Apple Silicon Mac，Swift 6.3.3、Node.js 26。

## 已完成修改

1. 「一起读懂」标题右侧新增独立字号选择：14、16、18、20、22。默认 14，随当前账号设置保存；正文、实时回复、思考内容和网页来源随之调整。中间阅读区字号保持独立。
2. 专注阅读消息不再生成头像元素；成员名称使用更大字号和粗体，长名称允许换行。同人同日连续消息保留一个发言块，按当前阅读序列循环浅蓝、浅绿、浅杏，夜间配套暗色。
3. 已标记消息常驻显示柔金色标签与左侧短线。手动续读点显示独立标签；续读点移动、书签增加、删除及恢复后同步更新。支持同一条消息多个标记和书签、续读点同时显示。

## 验证结果

- 全部 Node 测试 203 项通过。包括发言块循环、筛选、前插历史、消息追加、虚拟窗口缓存和日期缓存不跨调用等回归。
- `bash scripts/test.sh` 在正常 macOS 环境退出码 0：本地存储、AI 请求模拟、钥匙串访问策略模拟、附件、布局、OCR/文档提取、流式响应、缓存清理、并发保存与搜索模拟测试通过。初次受限环境的 OCR 系统调用失败，转到正常系统环境后通过。
- 原生 WKWebView 发言块验收通过：6 个发言块按 0、1、2、0、1、2 循环；追加同人或新人不破坏分组；无头像且姓名醒目；逐条选择、操作和连续边框保留；日夜各恰好三种背景。
- 原生 WKWebView 阅读外观验收通过：书签与续读点在不悬停且短暂跳转高亮结束后仍可见；续读点迁移清除旧标识；同一消息多个书签删至最后才消失，恢复后重新显示。
- 五档 AI 字号逐一验收，独立于中间字号。合成账号写入临时 JSON 后重新加载，22 号字号和标记均恢复。
- 280px 窄侧栏在 22 号字号下，中文、长链接、思考内容和来源无横向溢出。日间、夜间、窄侧栏截图已目视检查。
- 双架构应用包含 arm64 和 x86_64，版本为 1.0.3（构建 9）；应用资源与验收源码一致，签名完整性校验通过。
