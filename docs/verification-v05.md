# v0.5 个人偏好与快捷提问验收

日期：2026-10-18。范围：长期偏好、讨论临时要求、快捷提问及其持久化；保留 v0.4 阅读、文件和模型能力。

## 实现行为

- AI 输入区的「个人偏好」管理写作风格、展示格式、其他要求，支持增删改、启停和排序。初始长期偏好为空。
- 每次真实请求构造时加入当前启用偏好；优先级为最新明确提问 > 讨论临时要求 > 长期偏好。快捷提问和停用项不自动注入；参考资料中的文字不具备修改偏好的权限。
- 「本次要求」随原讨论持久化，新讨论清空；未发送讨论的临时要求单独保存。最近打开的讨论和资料在启动时恢复。
- 自定义快捷提问支持名称、内容、启停、排序、删除；点击只填入输入框。显式删除全部项目后重开保持为空。
- 数据按原微博账号保存，沿用原子写入和有效备份。偏好保存失败回滚本次字段，不回滚同时到达的消息；编辑草稿保留供重试。保存期间防止取消被误解为撤销写盘。
