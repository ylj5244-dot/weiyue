## 实现与边界

- 历史消息使用可变高度虚拟列表；检索仍覆盖全部本地消息。保存请求合并，原生验证、序列化、磁盘写入移到串行后台。阅读进度保存不再反复扫描全部记录配置同步。
- 分类清理支持当前群／全部群、文字／图片／文档，先预览后确认。保护标记（含最近删除）、收藏（含最近删除）、讨论、当前AI资料与阅读锚点。文件进入系统废纸篓，文本保留私有恢复快照。清理失败回滚；撤销保留后来同步的消息；旧内容抑制自动重新下载。
- 收藏支持单选、多选、搜索后全选、数量确认、撤销与持久「最近删除」。保留源聊天与已有讨论。
- 默认优先模型直读。DeepSeek Flash 的图片直接提交，PDF通过原始页面图像，不运行OCR；支持文件输入的模型可接收PDF文件。Word及普通文本使用正文提取。本机OCR仍可显式选用。直读PDF上限50页，页面图像上限12页，超限拒绝，不截断冒充完整。
- 深度思考三选；刷新每次请求服务模型列表并绕过缓存。官方 `deepseek-flash` 是API ID，Flash-1017是截至本次核验的版本名。
- Enter发送、Shift+Enter换行、中文输入法防误发；真实阶段、耗时、思考与回答增量；截断／一次性返回提示；取消与账号切换保留已收到部分。

- 顶部外观菜单提供跟随系统／日间／夜间，保存为独立工作区偏好；AppKit窗口与本地阅读界面同步，保持原有三栏布局。

## 自动与隔离验收

`bash scripts/test.sh` 覆盖消息模型、合并归档、无限标记、各群锚点、收藏删除恢复、清理保护与撤销、服务参数、源身份绑定、UTF-8 SSE、取消、模型列表、Word/PDF/OCR、文件与账户隔离、并发存储。

`bash scripts/test-desktop-ui.sh` 使用实际发行HTML/CSS/JS和原生WKWebView，只访问临时合成状态，无真实网络、凭据或用户资料。测试5,000条消息、深历史跳转、100次滚动、收藏删除恢复、IME/Enter、实时AI显示、清理预览/执行/撤销与重放抑制。最终 132 项 JavaScript 测试通过；原生存储、隔离与文件处理测试通过，SSE 61 项断言、直读输入 17 项断言通过。5,000 条消息的 100 次滚动，帧间隔中位 17 ms / P95 18 ms，输入到下一帧 P95 23 ms，最多挂载 29 张卡片。详见 `build/v04-tests.log`、`build/v04-js-tests.log` 与 `build/v04-desktop-tests.log`（本机忽略产物）。

原生实测发现并修复：DOM逐个移入片段时，WebKit把暂空列表的scrollTop夹为0。单独验证帧率或显式书签跳转不足以发现这个问题；增加真实前进、到达最后一条及同步后保持锚点的断言。
