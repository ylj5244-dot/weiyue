# 微阅 1.0.8：阅读、停止与皮肤

本轮在 1.0.7 基础上完成八项指定调整，以及补充的关闭窗口后继续后台运行。

| 调整 | 使用方式与结果 |
|---|---|
| 后台运行 | 点击左上角红色关闭按钮后只关闭窗口，微阅进程及当前工作继续运行。点击 Dock 中的微阅图标恢复原窗口；选择菜单「退出微阅」或按 Command+Q 才真正退出。 |
| 停止 AI | 回答、逐条翻译或附件读取进行中，输入区显示红色「停止」。点击后中止本次操作，已经收到的回答和原提问保留；迟到结果不会进入新的讨论。时段总结仍可用原「停止任务」，右侧也可停止。 |
| 新建讨论 | 点击「一起读懂」右上角的加号，本次讨论资料与输入框清空。旧讨论的资料快照和回答保留在「历史」。 |
| 五档密度 | 「设置 → 阅读与皮肤」中选择紧凑、偏紧、标准、舒展、宽松。同时改变专注阅读的文字行距与消息间距，字号仍由原下拉控件独立调整。默认是标准。 |
| 进入待机 | 阅读区顶部使用带金属外环、立体圆帽和电源图案的按键。点击后的待机与同步规则沿用原逻辑。 |
| 复制消息 | 消息浮动操作的第一项是「复制」。复制原文的换行与空格；带附件的消息同时复制附件名称及已有的 HTTP(S) 链接，不凭空生成附件正文。 |
| 皮肤与字体 | 在「设置 → 阅读与皮肤」选择界面皮肤、本机字体，或导入微阅 JSON 皮肤、TTF／OTF 字体文件。导入字体保存在微阅的数据目录，重启后继续可用。 |
| 书签备注 | 备注移到书签预览的时间行右侧，并保留卡片内边距。 |
| 选中按钮 | 续读点、书签、收藏等选中背景位于按钮内部，不再依靠向外扩张的阴影。 |

关闭窗口与退出应用是两个操作。更换安装包前请使用「退出微阅」或 Command+Q；只点关闭按钮会保留旧版进程。Mac 睡眠、断网或微博登录失效时，同步仍受原有条件限制。

设置改变后立即保存。点击「恢复默认」会恢复标准密度、默认皮肤和系统字体；已导入的皮肤与字体仍留在列表中，可再次选择。主界面、专注阅读与一起读懂使用所选字体；官方微博网页和系统窗口使用其自身外观。

## 导入皮肤

在设置中点击「导出可改写的样例」，修改得到的 `纸页青绿.weiyue-skin.json` 后，再点「导入皮肤」。源码和交付目录也附有相同样例。

顶层字段包括：

- `format`：固定为 `weiyue-skin`。
- `version`：固定为数字 `1`。
- `name`：下拉框显示的皮肤名称，最多 80 字符。
- `fontFamily`：可选的本机字体家族名称，例如 `PingFang SC`。本机没有此字体时，会提示并使用系统字体；可再通过字体下拉框选择已经导入的字体。
- `light`、`dark`：分别用于日间和夜间模式，跟随原来的「外观」选择。

两套配色都使用以下字段；颜色为六位十六进制值，例如 `#277860`，未提供的颜色沿用默认值。

| 字段 | 含义 |
|---|---|
| `background` | 窗口底色 |
| `panel` | 内容面板与控件底色 |
| `sidebar` | 侧栏及顶部、底部装饰区域 |
| `text` | 主要文字 |
| `secondary` | 辅助文字 |
| `accent` | 强调色、链接与主要按钮 |
| `line` | 边框与分隔线 |
| `soft` | 柔和区域与选中背景 |

皮肤文件最多 64 KB，最多保留 64 个不同皮肤。同一份皮肤再次导入不会产生重复项。皮肤只包含配色与字体名称，不读取网页、脚本或任意样式表。格式错误时保留原设置。

## 导入字体

点击「导入字体」，选择一个 `.ttf` 或 `.otf` 文件。成功后自动应用，并出现在字体列表的「已导入字体」组。每个文件最多 32 MB，最多保留 32 个不同字体文件；再次导入相同文件会复用已有项目。

字体文件没有包含的汉字或符号由系统字体补齐。字体文件的粗细与字形由该文件本身决定。无法解析的字体会显示错误；显示引擎无法加载时，会明确提示暂用系统字体。新安装到 macOS 的系统字体会在重新打开微阅后出现在「本机字体」组。

阅读密度、当前皮肤、字体选择和导入文件保存在 `~/Library/Application Support/WeiboReader/阅读与皮肤/`，独立于账号聊天档案。按照安装说明迁移整个微阅数据文件夹时，这些设置与导入资源会一起迁移。

## 本轮不涉及的内容

原有同步与未读规则、书签／收藏内容、AI 模型配置、密钥保存、附件一键解读／翻译以及媒体预览功能继续沿用。安装包与源码包均不包含用户账号资料、聊天、登录态或密钥。
