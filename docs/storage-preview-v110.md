# 微阅 1.0.10：存储、搜索与右侧预览

版本 1.0.10，构建 16。

## 存储与自动清理

从「设置 → 存储与自动清理」进入。这里显示微阅资料目录的磁盘占用，分别列出聊天记录与设置、图片与文档缓存、备份与恢复副本；总量包含本机所有微阅账号，当前账号消息数量另列。可刷新统计、打开手动清理，以及展开本地保存路径。

定时自动清理默认关闭。开启后选择保留最近 1、2、3 或 4 天并保存，应用立即检查；运行期间每小时检查，退出时暂停，下次启动或唤醒补查。时间按消息的发送时间与滚动天数计算；没有可靠时间的消息保留。

书签及最近删除的书签、收藏、讨论引用、阅读位置、尚未发送的讨论资料、正在阅读或勾选的消息、正在预览的资料和手动导入文件会受到保护。共享缓存只要仍被保留资料引用，就不会删除。自动清理直接删除到期的本地记录与无引用缓存，并同步缩减当前账号备份；不经过废纸篓，不创建撤销副本。微博原始消息不受影响，自动同步不会把已到期记录重新填满。

手动清理保留原来的预览、确认和撤销流程；文件进入系统废纸篓。手动清理与自动清理的恢复方式不同，界面会说明。

## 分类搜索与关注发言

阅读区搜索下方提供「全部、链接、图片、文件、视频」。关键词同时匹配正文、附件名和链接地址，可与成员、日期筛选一起使用。筛选仅覆盖本地已保存记录；一条消息有多种附件时，可出现在对应的多个类别中。

左侧新增「关注发言」。在「设置 → 重点关注人员」维护成员后，这里会集中展示他们在当前账号已保存群聊中的发言。可切换所有群聊或单群，继续使用关键词、日期和类型筛选；每条显示来源群，并可定位原消息。这个视图不改变各群阅读进度。

关注提示使用更宽的边标、加粗姓名与常驻徽标，连续发言也保留提示。专注阅读中，发送者 ID 与当前账号 ID 相同的消息靠右展示，并标注「我」；同名成员不会被当作本人。

## 链接、文档与图片

链接和文档改为紧凑标题行，不重复显示与标题相同的正文。点击链接，在右侧独立浏览器阅读，支持前进、后退和刷新，右上角可交给 Mac 默认浏览器。点击文档，右侧调用系统文档预览，右上角可用默认应用打开。预览不会清空原 AI 讨论，关闭即可返回。

网页预览使用独立临时会话，不共享微博登录会话。需要登录、拒绝内置访问或系统不支持预览的内容，可使用右上角的外部打开入口。

图片保持原始比例并居中，竖图、横图和多图采用适配布局。点击图片仍进入可缩放的独立窗口；图片和文档的解读、翻译、更多操作保留。

## 消息间距与操作速度

「设置 → 阅读与皮肤 → 同一成员消息间距」的独立五档额外间隔为 0、8、20、38、64 px，比旧版更容易看出差异。实际正文之间还包含原有操作栏留白。选择「跟随阅读密度」仍沿用密度设置；独立档位不会被正文密度覆盖。

书签与手动续读点点击后立即显示目标状态，保存期间显示处理中，保存失败恢复原状态并提示重试。底层保存减少重复解析和编码，保留版本冲突检查、原子写入和回读验证。

验证方法与范围见 [1.0.10 验收记录](verification-v110.md)。
