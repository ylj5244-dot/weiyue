# 微阅 1.0.11 使用说明

本次修改阅读布局、图片/网页预览和设置组织。公开下载版本仍为 1.0.9，本版本先在本机验收和使用。

## 当前群的关注阅读

左侧不再单列“关注发言”。进入群聊的专注阅读后，使用搜索框下方“全部发言 / ★ 只看关注”切换；“管理”进入重点关注设置。

全部发言中的关注成员仍有明显边线和底色。同一成员连续发言保留原有分组，姓名和重点关注标志只在组首出现。只看关注只筛选当前群，不跨群汇总，也不覆盖未筛选时的阅读位置。

完整的“某某撤回了一条消息”提示在专注阅读中隐藏；本地原记录与微博官方页面不变。

## 消息背景与间距

背景宽度根据文字、字号、表情、附件及操作栏所需空间自动计算。短消息收窄，长消息以阅读区边界为限。连续成员组采用统一宽度；自己的发言继续靠右。

设置 → 阅读与皮肤 → 同一成员消息间距：五档分别追加 0、16、40、80、144px 间隔，仍可选择“跟随阅读密度”。增加的是消息间距，正文行距由阅读密度独立控制。字号和字体调整会同步重算消息宽度。

## 图片、表情与网页

聊天中的图片缩略图保持紧凑。点开高宽比至少 2:1 且高度至少 600 像素的长图，默认从顶部按窗口宽度显示，可滚动阅读；调整预览窗口宽度时保留当前阅读段落。“查看全图”显示完整图片，“适应宽度”回到顶部阅读。普通图片仍完整适配，缩放、拖动、原始大小、关闭方式保留。

内置 75 个微博常用表情，包括 [二哈]、[笑cry]；截图中的旧格式 [/ee9092.png] 显示为 😂。未知标记原样保留。原消息、搜索和复制文本保留原始表情标记。

网页预览根据右栏宽度调整正文和图片，固定宽度页面可重新排版；“原网页”恢复原布局，“适应侧栏”重新开启。网站登录、访问权限和验证页仍由网站决定。不是所有网页结构都能识别为正文，复杂网站可切回原网页或使用默认浏览器。页面原有导航和交互弹窗应保持可用。文档继续使用原生预览。

## 设置导航

设置采用左分类、右内容：阅读与皮肤、重点关注人员、个人偏好、AI 模型服务、存储与自动清理。切换分类保留未保存的输入；关闭设置会结束当前编辑，保存后的内容持续有效。阅读设置即时保存，重点关注和个人偏好使用各自的保存按钮。点击右侧模型名称直接打开 AI 模型服务。

缓存清理从存储分类进入，完成后可返回存储设置。自动清理保存后在关闭设置时检查，此后继续原有定时检查。
