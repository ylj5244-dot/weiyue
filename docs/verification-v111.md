# 微阅 1.0.11 验收记录

验证日期：2026-10-21。基线为 1.0.10（构建 16），本版为 1.0.11（构建 17）。测试使用合成账号、6006 条合成消息、临时文件与仅监听本机的网页服务，没有清理真实聊天或调用真实 AI 服务。

## 本次功能

- 关注阅读移到当前群的中间阅读区，提供「全部发言 / 只看关注」。关注成员在全部发言中同样突出；连续成员组只在第一条显示姓名、时间与关注标志。筛选不覆盖普通阅读位置，切群及账号切换正确清除临时筛选。
- 消息背景按文字、字号、表情、姓名、操作栏与附件计算宽度。同一连续成员组宽度一致，自己的消息继续靠右。短消息收窄，长消息自然换行；字体和字号调整、筛选、追加消息及窗口变化后重新计算。
- 同一成员消息间距五档追加 0、16、40、80、144 px；默认测试字号与密度下实际正文间隔为 24、40、64、104、168 px。最高档重载后仍保持；原来的跟随密度模式保留。
- 搜索与全部、链接、图片、文件、视频筛选同排，在 926、560、430 px 阅读区检查边界和对齐。
- 设置分为阅读与皮肤、重点关注人员、个人偏好、AI 模型服务、存储与自动清理五类。切换分类、进入手动清理再返回均保留未保存草稿；保存和关闭行为分别验证。
- 75 个常用微博表情使用已核验的本地 PNG；[二哈] 与相邻表情正常显示。截图中的旧标记 [/ee9092.png] 显示为 😂；未知标记原样保留，搜索、复制和原记录保持原文本。
- 完整的撤回通知在专注阅读隐藏；讨论撤回行为的普通句子、带后续正文或附件的消息不会因此隐藏。
- 长图仅在点开预览后按窗口宽度从顶部阅读。调整窗口保留当前阅读段落，支持滚动、查看全图、适应宽度与手动缩放；聊天缩略图仍保持紧凑。
- 网页预览按右栏宽度调整固定宽正文和图片，支持恢复原网页。站点导航保留，过宽导航在自身区域滚动；弹窗不套正文适配。后退、前进、刷新、地址回传、外部打开和文档预览继续有效。

## 验收中修复的问题

- 430 px 阅读区的六按钮文档消息曾撑开布局轨道；窄栏改为姓名、动作分行，操作栏可换行，附件完整位于消息背景内。
- 短消息的宽度估算曾漏掉按钮内边距，导致宽栏普通姓名提前省略；按实际图标、间距、内边距和时间字号修正，并补充 14 / 18 字号的完整姓名断言。
- 从设置进入清理再返回曾丢失草稿；保留设置容器及编辑状态，三类未保存输入往返检查通过。
- 调整栏宽后的延迟恢复曾可能覆盖同群新书签跳转；恢复前核对账号、群和导航版本，真实页面组合检查通过。
- 原生长图工具栏在最小窗口曾有按钮重叠；紧凑布局下全部按钮保持可见和可点击。
- 网页适配曾影响正文旁的站点控件及动态弹窗；缩小适配范围、保留交互区域并补充导航与弹窗回归。

## 构建与范围

通用构建包含 arm64 与 x86_64，最低 macOS 14，使用本机 ad hoc 签名。构建前记录全部源码和资源摘要，发行核对时确认与构建内容一致。源码包按白名单导出，包含 MIT 许可证及 75 张表情图片的来源说明；不复制构建目录和用户资料。

实际运行与图形验收在本机 Apple Silicon 上完成；Intel 为交叉编译。网页验收使用合成页面，不能据此声称任意站点都已验证。截图中的微博链接在匿名访问时进入访客验证，未将该帖正文计为在线验收通过。复杂网站可切回原网页或使用默认浏览器。

复验入口：`node --test tests/*.test.cjs`、`scripts/test-reading-refinement-ui.sh`、`scripts/test-content-preview-responsive.sh`、`scripts/test-attachment-preview-ui.sh`。图形检查需要已登录的 macOS 桌面。结果与截图保存在本机 `build/`；发行及安装回读分别记录为 `v111-release-verification.json` 和 `v111-install-verification.json`。
