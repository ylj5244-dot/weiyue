# 微阅 1.0.12 验收记录

验证日期：2026-10-21。基线为 1.0.11（构建 17），本版为 1.0.12（构建 18）。本轮收紧群信息、阅读工具及位置导航，消息正文、连续分组、关注强调、表情与附件功能沿用原有实现。

## 布局与操作

在 1024 CSS px 阅读栏中，群信息至正文起点由 244 px 降至 98 px，减少 146 px，约 59.8%。群信息与常用工具各一行；820 px 同样为两行。650 px 阅读栏合计 133 px，430 px 合计 148 px，按可用空间换行，搜索与五种类型同排。

同步详情集中在群名旁菜单，保留记录范围、时间、详细状态、立即同步和每次加载 500 条历史。成员与日期集中在筛选菜单；生效条件、匹配数和清除入口按需显示。关注管理继续打开设置中的对应分类。

手动续读点、返回跳转前和最新移至阅读区右下角。三类位置独立保存；查看最新不覆盖手动点，返回恢复原消息和像素偏移。末条消息预留空间，多选操作栏不与位置导航重叠。

## 发现与修复

- 宽栏搜索框最初过长，收敛为上限 196 px；窄栏上限 280 px，保持与消息类型同排。
- 旧阅读验收依赖已移除的搜索行外壳，定位改为兼容新工具栏容器，原有尺寸、对齐和功能断言未放宽。
- 官方模式新增消息后，同步弹层结果数最初停留在旧值。改为共用当前阅读结果逻辑独立更新；新增 Node 实际函数与原生事件回归先在旧实现复现失败，修复后通过。系统通知排除、来源快照和去重保持。

最终视觉对照使用用户确认图与真实 WKWebView 截图，在相同的 1024 px 阅读栏及 2 倍像素密度下比较。完整报告见 [视觉验收](../design-qa.md)。

## 环境与复验

图形验收运行于本机 Apple Silicon macOS，使用非持久 WebKit 会话、合成消息、内存 RPC 和临时文件，阻断所有远程资源及网络请求。没有运行真实 AI 请求或更改真实聊天资料。Intel 为交叉编译和架构检查，本轮没有 Intel 真机结果。

构建前记录 137 个源码、资源及构建脚本的 SHA-256。发行核对要求构建前快照一致，并逐文件比对应用 ZIP、只读挂载的 DMG、构建产物及资源源码。源码按白名单导出，包括 MIT 许可证和 75 张表情图片，不含用户资料及构建缓存。发行检查和安装回读分别写入本机 `build/v112-release-verification.json` 与 `build/v112-install-verification.json`。

复验入口：

```sh
node --test tests/*.test.cjs
bash scripts/test.sh
bash scripts/test-compact-reader-ui.sh
bash scripts/test-reading-refinement-ui.sh
```

结果与截图位于本机 `build/`。外部微博和模型服务可用性不属于本次离线验收结论。
