# 微阅 1.0.12：紧凑阅读工具栏

群信息和常用工具集中在阅读区顶部。宽窗口下，群名、同步状态、待机和阅读模式一行；关注范围、搜索、消息类型、筛选、时段总结和字号一行。窄阅读栏会分为两行，保留完整操作入口。

## 同步与历史

点击群名旁的同步状态，查看详细进度、更新时间、本地消息数量和起止时间。这里提供「立即同步」及「加载更早 500 条」。状态会区分正在同步、同步异常、暂停、尚未启用等情况。「历史未完整」提示保留，避免把已加载记录当成完整群历史。

## 筛选

「全部发言／只看关注」只影响当前群。搜索可以与链接、图片、文件、视频类型组合使用。

点击「筛选」选择成员或起止日期，也可以打开重点关注人员管理。使用筛选时，工具栏下方显示当前条件、匹配数量和「清除筛选」。搜索范围始终是本地已经保存的记录。

## 阅读位置

右下角提供「最新」；跳转后出现「返回跳转前」。如果给某条消息设置过「从这里阅读」，还会显示手动续读点入口。滚动不会替换手动续读点，查看最新也不会清除它。

多选消息时，浮动位置按钮会避开底部操作栏。阅读末尾留有空隙，消息及其操作不会被浮动按钮覆盖。

## 其他操作

点击菜单外部或按 Escape 关闭下拉。时段总结、字号、官方聊天和待机仍使用原有入口与行为。消息正文、连续分组、关注强调、表情和附件预览沿用上一版。

安装及迁移方法见 [安装说明](install-and-build.md)。
