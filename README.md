# 📖 微阅

Mac 上的微博群聊阅读与 AI 讨论工具。把消息读清楚，把资料留下来，在原文旁边继续提问。

## ⬇️ 下载与安装

[📦 下载 Mac 安装包](https://github.com/ylj5244-dot/weiyue/releases/download/v1.0.9/weiyue-1.0.9-macOS-universal.dmg) · [🗜️ ZIP 备用包](https://github.com/ylj5244-dot/weiyue/releases/download/v1.0.9/weiyue-1.0.9-macOS-universal.zip) · [📋 全部下载与说明](https://github.com/ylj5244-dot/weiyue/releases/latest)

适用 macOS 14 及以上，安装包包含 Apple Silicon 与 Intel 架构。打开 DMG，将「微阅」拖入「应用程序」即可。当前版本 1.0.9。

应用尚未完成 Apple 签名与公证，首次打开可能被系统拦截，请参阅[安装说明](docs/install-and-build.md)。Intel 已交叉编译，尚未完成真机验收。

## ✨ 能做什么

💬 专注读群聊：选择多个群同步，按成员、日期或关键词筛选本地记录；突出重点成员，自动记住每个群的阅读位置。

🔖 保存有价值的内容：添加带备注的书签，收藏单条或多条消息，在资料库中搜索、导出，随时定位原文。

🤖 边读边问 AI：选取消息、图片或文档，解释概念、比较观点、继续追问。讨论历史自动拟题，支持个人偏好与快捷提问。

🕒 按时段总结：指定时间范围，梳理错过的讨论；长记录自动分批处理，总结保留可回看的消息引用，并提示记录完整性。

📑 解读与翻译：支持聊天翻译、图片与文档解读，也可导入 PDF、Word 等本地资料。可选联网搜索，回答保留网页来源。

🎨 舒适的阅读界面：可调整的三栏布局、独立字号、日夜模式、三套皮肤，以及字体、阅读密度和连续消息间距设置。

## 🚀 三步开始

① 在应用内的微博官方网页扫码登录。

② 在「我的群聊 → 管理」中勾选需要同步的群。

③ 需要 AI 时，配置自己的 API 地址、Key 和模型，选取资料即可提问。

支持兼容 Chat Completions 的 HTTPS 服务；图片、PDF 与思考能力取决于模型。联网搜索目前支持 DeepSeek 官方服务，调用费用以服务方为准。

## 💾 数据与同步

聊天、收藏、讨论和附件按账号保存在本机，API Key 存入 macOS 钥匙串。发起 AI 操作时，相关内容会发送给你配置的服务；讨论自动拟题也会调用模型。

关闭窗口可继续后台运行；休眠、断网或微博限流会影响同步。微阅是第三方工具，本地提醒与微博官方未读数相互独立。
